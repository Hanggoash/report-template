# report-template

把老师的要求文档或截图交给 Agent，讨论方案、完成任务，再生成报告 PDF 和可编辑的 TeX 源文件。

内置实验报告、文科报告和 Beamer 汇报三套模板，附带所需字体、图片和使用手册。可以新建报告，也可以接着修改已有报告。

## 安装

本仓库就是技能目录。若仓库位于桌面的 `Develop/report-template`，在 Codex 中可通过符号链接安装：

```sh
mkdir -p ~/.codex/skills
ln -s ~/Desktop/Develop/report-template ~/.codex/skills/report-template
```

目标位置已有同名技能时，先检查再处理。如安装后未识别，重新加载技能或新建会话。

运行辅助工具需要 Python 3；生成 PDF 需要支持中文的 XeLaTeX 环境，例如 TeX Live / MacTeX，或支持完整项目的在线编译器。

## 使用

在对话中输入 `$report-template`，附上要求文档、截图或已有材料：

```text
$report-template 这是数据库实验三的要求，先和我讨论方案。
$report-template 用文科模板完成这次实践报告，材料已附上。
$report-template 根据这份报告制作一个 8 分钟的 Beamer 汇报。
```

Agent 会整理要求、推荐模板，并与你确定分工。你也可以直接指定模式：

| 模式 | 分工 | 可以这样说 |
| --- | --- | --- |
| `automatic` 自动执行 | Agent 完成核心任务、验证结果并制作报告；你提供材料和审阅成果 | “确定方案后，由你自动完成。” |
| `guided` 手动引导 | 你亲自操作，Agent 分步指导、核对结果并整理报告 | “我想自己做，请一步步教我，并告诉我在哪里截图。” |
| `hybrid` 混合协作 | 双方分担核心任务，Agent 汇总结果并制作报告 | “你写代码，我在学校环境运行和截图。” |

三种模式都可以由 Agent 写报告，区别在于实验、代码实现、数据处理等核心任务由谁完成。模式可中途调整；自动执行受当前环境和可用设备限制。

引导或混合模式中，按提示完成操作，再把截图、数据或报错发回对话。下次继续时，说明任务名称：

```text
$report-template 继续“数据库实验三”，这是刚完成的截图。
```

## 文件保存在哪里

每份作业保存在独立目录，默认位置为 `~/Desktop/College/课程作业/日期-任务名称/`。开始时可以指定其他位置。

- `report/`：报告源文件、字体和正文图片。
- `deliverables/`：最终 PDF 和提交包。
- 其余目录和记录文件：原始材料、实验结果、工作文件与进度，供后续继续使用。

新作业复制模板，已有作业保留自己的版本。修改技能中的 `assets/templates/` 只影响之后新建的作业。
