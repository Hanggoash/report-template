# Beamer 汇报

模板：`../assets/templates/beamer/main.tex`，复制整个 `beamer/`，包括 `fonts/`。详细组件见随附 `Beamer模板使用手册.pdf`。

- 输出为 16:9 的 Beamer PDF，不承诺将 TeX 直接转换成可编辑 PowerPoint。
- 集中填写 `TalkTitle`、`ShortTitle`、`TalkSubtitle`、`Presenter`、`Affiliation`、`Department`、`TalkDate`、`ContactEmail` 和页脚配置。可选信息没有时留空或关闭显示。
- 项目内 `fonts/SourceHanSansCN-Regular.otf` 和 `fonts/SourceHanSansCN-Bold.otf` 应完整保留；同时保留 `fonts/LICENSE.txt`。项目缺字体时可回退，因此应确认最终使用的是预期字体。
- 先确定听众、汇报目标和时长，再讨论内容结构和页数。课程实验可围绕问题、方法、结果与结论组织，不能仅把报告段落逐页粘贴。
- 保留模板的章节导航、颜色和页脚体系；首个章节 frame 的标题栏行为以模板现有实现为准。需要新图时使用可编辑图形、真实数据图或用户提供的图片。
- 检查每页可读性、公式与图例字号、页脚、导航、总页数和附录；根据用户需要另提供讲稿或演讲备注。
